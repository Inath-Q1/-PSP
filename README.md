# -PSP

课程作业仓库

## 项目简介

本仓库为课程相关作业，主要内容涉及多目标优化、智能算法及其在经济调度等领域的应用。代码使用 MATLAB 编写，包含粒子群优化等方法，并配有示例数据文件。

## 目录结构

- `crowding_distance.m`：计算种群中个体的拥挤度距离，用于多目标优化排序。
- `diversity_metric.m`：计算粒子的多样性度量。
- `economic.m`：经济性目标函数，结合风电、光伏、柴油机、储能等多种能源的成本与污染估算。
- `fitness.m`：适应度函数，用于衡量解的优劣。
- `qiantuihuidai.m`：前推回代函数，通常用于能量管理或负载分配的动态计算。
- `non_dominated_sorting.m`：非支配排序函数，常用于多目标进化算法中进行帕累托分层。
- `P.mat`、`PV.mat`、`WT.mat`：仿真所需的典型数据，分别为负载、光伏和风电数据。
- 其他相关 MATLAB 文件：如调度约束、辅助函数等（可根据具体内容补充）。

## 快速开始

1. **准备环境**  
   推荐 MATLAB 2016a 及以上版本，确保可读取 `.mat` 文件。

2. **运行说明**  
   - 先加载数据文件，例如：
     ```matlab
     load('P.mat');
     load('PV.mat');
     load('WT.mat');
     ```
   - 按照主函数或脚本说明顺序运行优化算法及经济性评估。

3. **主要函数说明**
   - `crowding_distance(particle, population)`：用于多目标粒子群中计算个体拥挤度，有助于保持解的多样性。
   - `diversity_metric(particle)`：计算群体多样性，通常以标准差衡量。
   - `economic(x)`：计算给定调度方案的总经济成本，并考虑污染排放等。
   - `fitness(x)`：适应度函数，综合评价解在各目标下的表现。
   - `qiantuihuidai(x, ...)`：前推回代函数，可用于能量平衡、系统调度等动态计算。
   - `non_dominated_sorting(population)`：实现非支配排序，输出多目标优化中的帕累托分层结构。

## 数据说明

- `P.mat`：包含负载曲线数据。
- `PV.mat`：包含光伏发电数据。
- `WT.mat`：包含风电发电数据。

## 结果与分析

### 小生境粒子群算法与传统粒子群算法的对比

本项目通过仿真实验证明，小生境粒子群算法（Niche PSO）在多目标优化与经济调度问题中，相较于传统粒子群算法（Standard PSO）表现出更优的多样性保持能力和全局寻优能力。

- **多样性**：小生境粒子群算法通过引入拥挤度距离和多样性度量，有效避免了种群早熟收敛，能获得更丰富的帕累托前沿解集。
- **收敛性**：实验结果显示，小生境PSO在大多数运行中能更快找到收敛解，且全局最优解的质量普遍高于传统PSO。
- **适用性**：在能源调度、经济性与环保性目标综合优化场景下，小生境PSO能够给出更多样化的调度策略选择，便于决策者权衡不同目标。

> 具体实验数据和收敛曲线可参考项目中的仿真结果输出。
